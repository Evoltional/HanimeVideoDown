# Hanime视频下载器

一个基于Python开发的图形化视频下载工具，专门用于从Hanime等网站批量下载视频内容。

## 🌟 功能特点

- **图形化界面**：基于PyQt5开发的现代化用户界面
- **批量下载**：支持从视频列表页面批量下载多个视频
- **多任务管理**：同时管理多个下载任务，支持暂停、恢复、删除操作
- **断点续传**：程序异常退出后可恢复未完成的下载任务
- **智能识别**：自动识别视频链接并提取下载地址
- **配置持久化**：自动保存下载路径、窗口位置等用户设置
- **实时日志**：显示详细的下载进度和状态信息

## 📋 系统要求

- **操作系统**：Windows 10/11
- **Python版本**：3.8 或更高版本
- **浏览器**：Google Chrome（自动下载和管理）

## 🔧 安装依赖

```bash
pip install -r requirements.txt
```



## 🚀 快速开始

### 1. 运行程序

```bash
python VideoDown.py
```

### 2. 基本使用步骤

1. **设置下载路径**：点击"更改路径"按钮选择视频保存位置
2. **输入链接**：在输入框中粘贴Hanime视频列表页面的URL
3. **开始下载**：点击"开始下载"按钮启动下载任务
4. **管理任务**：使用暂停、恢复、删除等功能管理下载任务

### 3. 使用技巧

- **粘贴功能**：可以使用"粘贴"按钮快速从剪贴板获取链接
- **无头模式**：勾选"无头模式"可在后台运行，不显示浏览器界面
- **批量操作**：
  - 点击"暂停下载"暂停所有任务
  - 点击"删除全部"清空所有任务
  - 输入框为空时点击"开始下载"可恢复所有暂停和失败的任务
- **任务恢复**：程序重启后，所有未完成任务（包括之前运行中的任务）都会以暂停状态恢复，需要手动点击"继续"按钮开始下载

## 📁 项目结构

```
VideoDown/
├── VideoDown.py           # 程序入口文件
├── requirements.txt       # 依赖包列表
├── config.json           # 用户配置文件（自动生成）
├── Logger/               # 任务日志目录
│   └── TaskLogger.json   # 任务状态记录文件
├── Download/             # 默认下载目录（可自定义）
└── ToolPart/            # 核心模块目录
    ├── Config.py        # 配置管理模块
    ├── DownLoad.py      # 视频下载核心模块
    ├── GUI.py          # 图形界面模块
    └── TaskLogger.py   # 任务日志管理模块
```
