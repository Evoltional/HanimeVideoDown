# 🎬 Hanime 视频下载器

<div align="center">

一个基于 Python 开发的图形化视频下载工具，专门用于从 Hanime 等网站批量下载视频内容。

![PyQt5](https://img.shields.io/badge/PyQt5-5.15.9-green.svg)
![Platform](https://img.shields.io/badge/Platform-Windows-lightgrey.svg)

✨ **特点**: 图形化界面 · 批量下载 · 断点续传 · 智能任务管理 · Cloudflare 绕过 · 重复检测

## 🌟 核心功能

### 基础功能
- **🖥️ 现代化 GUI 界面**：基于 PyQt5 开发的深色主题用户界面，操作直观友好
- **📥 批量下载**：支持从视频列表页面批量下载多个视频，自动提取所有链接
- **⚡ 并发控制**：智能队列调度，默认 2 个任务同时下载，可自定义调整
- **💾 断点续传**：程序异常退出后可恢复未完成的下载任务，无需重新开始

### 高级特性
- **🔍 智能识别**：自动解析网页结构，精准提取视频下载地址
- **🔄 失败重试**：下载失败的链接可手动或自动重试，提高成功率
- **🎭 Bypass 模式**：内置 Cloudflare 绕过功能，处理网站验证问题
- **👻 无头模式**：后台静默运行，不显示浏览器窗口，节省系统资源
- **✨ 重复检测**：智能识别已下载文件，避免重复下载，节省时间和带宽

### 任务管理
- **⏸️ 灵活控制**：支持暂停、恢复、停止单个或全部任务
- **📊 实时进度**：显示每个任务的下载进度、速度和完成数量
- **📝 详细日志**：记录所有操作步骤，支持性能分析和故障排查
- **💼 配置持久化**：自动保存下载路径、窗口位置、用户偏好设置
- **📂 双目录管理**：独立的下载路径和存储路径，灵活管理临时文件和最终文件

### 3️⃣ 基本使用流程

<div align="center">

**设置路径** → **输入链接** → **开始下载** → **管理任务**

</div>

#### 详细步骤

1. **设置下载路径**
   - 点击「更改路径」按钮选择视频保存位置
   - 点击「打开目录」可快速跳转到下载文件夹

2. **输入视频链接**
   - 在输入框中粘贴 Hanime 视频列表页面的 URL
   - 或使用「粘贴」按钮从剪贴板快速获取
   - 示例格式：`https://hanime1.me/watch?v=????`

3. **配置选项**（可选）
   - ✅ **无头模式**：勾选后后台运行，不显示浏览器界面
   - ✅ **Bypass 模式**：遇到 Cloudflare 验证时启用

4. **管理存储目录**（新增）
   - 点击「选择存储目录」设置视频文件的最终存储位置
   - 点击「打开存储目录」快速查看已下载的视频
   - 程序会自动扫描存储目录，记录所有现有视频文件
   - 下载前会检查文件是否已存在，避免重复下载

5. **开始下载**
   - 点击「开始下载」按钮启动下载任务
   - 任务将显示在下方「活动下载任务」区域
   - 日志区会实时显示文件跳过、下载进度等信息

6. **任务管理**
   - ⏸️ **暂停全部**：暂停所有正在下载的任务
   - ▶️ **恢复任务**：对已暂停/失败/停止的任务点击「继续」
   - ⏹️ **停止全部**：停止所有任务（保留进度）
   - 🗑️ **删除全部**：清空所有任务（包括日志记录）

## ✨ 新增功能详解

### 📂 双目录管理系统

#### 功能说明
程序现在支持两个独立的目录设置：
- **下载路径**：临时下载文件的保存位置
- **存储目录**：最终视频文件的存储位置

#### 使用场景
```
场景 1: 不同磁盘管理
- 下载路径：D:\Temp（SSD，速度快）
- 存储目录：E:\Videos（HDD，容量大）

场景 2: 分类管理
- 下载路径：C:\Downloads（默认位置）
- 存储目录：D:\Anime\Hanime（分类整理）
```

#### 操作步骤
1. 点击「更改路径」设置下载临时文件位置
2. 点击「选择存储目录」设置最终存储位置
3. 两个目录可以相同，也可以不同
4. 程序启动时会自动扫描存储目录

### ✨ 智能重复检测

#### 工作原理
1. **Exis.json 文件**：程序在 `Logger` 文件夹中维护一个视频文件名数据库
2. **自动扫描**：每次启动程序或更改存储目录时，自动递归扫描所有子文件夹
3. **格式支持**：支持 .mp4, .avi, .mkv, .mov, .wmv, .flv, .webm 等常见视频格式
4. **实时检测**：下载前检查文件名是否已存在于数据库中

#### 优势
- ✅ **节省时间**：跳过已存在的文件，无需重新下载
- ✅ **节省带宽**：避免重复占用网络资源
- ✅ **智能识别**：即使文件在不同子文件夹中也能检测到
- ✅ **自动更新**：更改存储目录后自动重新扫描

#### 日志输出示例
```
[12:30:45] INFO - ✓ 文件已存在（Exis.json记录），跳过下载: video_001.mp4
[12:30:46] INFO - ✓ 文件已存在，跳过下载: video_002.mp4
[12:30:47] INFO - ▶ 开始下载: video_003.mp4
[12:31:20] INFO - ✓ 下载完成: video_003.mp4
```

### 📊 增强的日志系统

#### 新增日志类型
- **✓ 成功类**：文件跳过、下载完成等操作
- **▶ 开始类**：开始下载新文件
- **✗ 失败类**：下载失败、重命名失败等错误
- **⚠ 警告类**：网络波动、重试提示
- **↻ 重试类**：整体重试、网络重试

#### 日志价值
- 实时监控每个文件的处理状态
- 快速定位问题和失败原因
- 了解下载进度和效率
- 便于故障排查和性能优化

## 📦 打包发布

### 安装打包工具

```bash
pip install pyinstaller
```

### 执行打包

#### 方式一：标准打包（推荐）
```bash
pyinstaller --onefile --windowed --name VideoDown VideoDown.py
```

#### 方式二：带图标打包
```bash
pyinstaller --onefile --windowed --name VideoDown --icon=app.ico VideoDown.py
```

### 打包参数说明

| 参数 | 作用 |
|------|------|
| `--onefile` | 打包成单个 exe 文件，便于分发 |
| `--windowed` | 不显示控制台窗口（GUI 程序专用） |
| `--name VideoDown` | 指定生成的可执行文件名称 |
| `--icon=app.ico` | 指定应用程序图标（可选） |

### 打包后清理

打包完成后，可以删除临时文件：
```bash
# 删除 build 文件夹
rmdir /s /q build

# 删除 spec 文件
del VideoDown.spec
```

### 分发说明

最终用户只需将 `dist\VideoDown.exe` 复制到任意位置即可运行，无需安装 Python 环境。

> ⚠️ **注意**：首次运行时会自动下载 ChromeDriver，请确保网络连接正常。


## 💡 使用技巧与最佳实践

### 高效下载策略

#### 🎯 批量任务处理
- **空输入恢复**：输入框为空时点击「开始下载」，可恢复所有未完成的任务
- **并发控制**：默认 2 个并发任务，避免网络带宽占满导致卡顿
- **优先级管理**：新任务会进入队列等待，当前任务完成后自动开始

#### 🛡️ 特殊情况处理
- **Cloudflare 验证**：如遇到"Checking your browser"页面，启用 Bypass 模式
- **网络不稳定**：启用失败重试功能，自动尝试下载失败的链接
- **大文件下载**：建议使用有线网络连接，避免 WiFi 波动

#### 📊 进度监控
- **实时日志**：查看详细的下载速度、剩余时间等信息
- **步骤追踪**：每个任务的解析、下载、合并步骤都有时间和状态记录
- **性能分析**：日志中包含各步骤耗时，便于优化和排查问题

### 常见使用场景

#### 场景 1: 下载整个系列
```
1. 找到系列视频的列表页面
2. 复制链接到输入框
3. 启用无头模式（可选）
4. 点击开始下载
5. 程序会自动下载所有集数
```

#### 场景 2: 断点续传
```
1. 程序意外关闭或网络中断
2. 重新启动程序
3. 所有未完成任务会自动恢复（暂停状态）
4. 点击「继续」按钮或直接点击「开始下载」（空输入）继续
```

#### 场景 3: 处理失败链接
```
1. 某些视频下载失败，显示红色"失败"状态
2. 点击该任务的「继续」按钮
3. 程序会重新尝试下载失败的链接
4. 或者勾选 Bypass 模式后重试
```

#### 场景 4: 避免重复下载（新增）
```
1. 程序启动时自动扫描存储目录
2. Logger/Exis.json 记录所有现有视频文件
3. 下载前自动检查文件名是否已存在
4. 如存在则跳过，日志显示"✓ 文件已存在，跳过下载"
5. 节省时间和带宽，提高效率
```

#### 场景 5: 双目录管理（新增）
```
1. 设置下载路径为 SSD（速度快）
2. 设置存储目录为大容量 HDD（空间足）
3. 临时文件快速下载，最终文件长期保存
4. 两个目录独立管理，互不影响
```
